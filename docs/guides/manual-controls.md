# 手动样例操作

当前可在本机 Windows / UE 5.8.4 运行。双击仓库根目录的 `Play-ManualVehicle.cmd`，打开已经构建、导入的哨兵；点击画面后操作。

| 输入 | 行为 |
|---|---|
| W / S | 沿镜头水平朝向前进 / 倒车，平滑加速、松键主动制动 |
| A / D | 相对镜头左右平移，普通和小陀螺模式一致 |
| Q / E | 普通模式手动车体旋转 |
| G / Z / X | 开关小陀螺 / 降低转速 / 提高转速 |
| Ctrl + WASD | 0.35m/s慢行，适合波浪段 |
| Space | 制动 |
| R | 车辆复位及训练重置 |
| 鼠标 | 观察、瞄准；炮塔跟随世界目标 |
| 按住 C | 自由观察，保持瞄准目标；松开回到瞄准方向 |
| Shift | 第三人称 / 瞄准镜切换 |
| 滚轮 | 第三人称调距离；瞄准镜调 30°–15° FOV |
| 按住右键 | 瞄准镜临时使用 15° FOV |
| Alt+F4 | 关闭样例 |

白色十字是当前观察方向；橙框在纯驾驶中表示炮口射线落点，训练模式表示考虑重力/碰撞的预计弹道落点。限位、视差、遮挡或弹道下坠时二者可能不同。

Play-Training.cmd进入射击训练：左键开火、R重置、HUD显示血量/弹量/热量/时间。[训练说明](training-combat.md)。

灵敏度在 `unreal/RMSim/Config/DefaultGame.ini` 的 `[RMSim.ManualControl]` 中调整，重启生效。`MouseSensitivity` 单位为度/鼠标原始计数，当前 0.04；增大更灵敏。瞄准镜按 FOV 降低灵敏度，避免重复使用引擎默认缩放。

需要重新编译或导入时使用 `tools/unreal/Start-ManualVehicle.ps1 -EngineRoot E:\simulator-tools\UE_5.8`。只启动不同的已导入包可用 `Run-ImportLab.ps1 -InputType MeshRig -InputFile <ue_mesh_rig.json>`。

## 已验证范围

- UE 5.8.4 本机编译、7 部件导入及尺寸核对。
- 9 项碰撞/关节/相机运行检查；18 项共用手动输入路径检查，包括制动、瞄准保持、自由观察、切镜和变倍。
- 真实窗口可操作，已记录 W/S/A/D/C/Shift/滚轮等事件及实际位姿变化。

默认已切换为15部件/13刚体四舵轮接触车辆，普通/小陀螺均镜头相对平移。旧7/11部件及运动学检查是历史证据。[最新操作、参数及验证说明](swerve-gyro-controls.md)。

独立舵轮转向已有原生实现；实车动力学校准、完整比赛裁判、联机或ROS自动驾驶闭环仍未完成。Ubuntu同源构建/碰撞准备入口已写，原生运行尚未验证。
