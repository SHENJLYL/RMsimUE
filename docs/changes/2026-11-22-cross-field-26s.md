# RMUC 跨场 26 秒验收

新截图对应 Windows 原生会话最后一条由右下到左上的完整跨场导航，日志中的起点为 (7.86, −6.78)，目标为 (−8.32, 6.16)，原动作为 48.70 秒。用户报告手操约 26 秒。原生日志只记录起点平面坐标，受控回放统一使用 0 弧度初始朝向。场景通过正常初始出生放置车辆，发出跨场目标后全程使用真实轮地接触。计时从目标发送到动作结果，途中停车和重规划计入。

## 改动与结果

- 将转向前视与速度参考解耦，按路径弯度和减速度向前预判速度。补偿定位位姿时间戳的滞后，控制前的车身扫掠仍从原位姿及速度预测。全局规划增加拐角净空间。
- 沿实际硬制动的加速度变化率积分停车距离，纳入位姿年龄、指令延迟和既有减速度上限。独立数值积分覆盖八个起始速度。
- 最快合格净空回放为 **40.90 秒**，物理时钟 40.90 秒，端点误差 17.5 厘米。3,311 个采样和插值姿态通过静态地图与外围净空检查。实际轨迹约 57.23 米，中途进入近停区间两次，目标仍高于 26 秒。
- 跨场最快候选的波浪及平台回归全部到达，其中进六边形平台的一段有两个采样姿态与同一静态占用格 (8.775, 5.275) 重叠，静态净空门禁失败。更激进的转弯速度及主动旋转候选产生进度丢失。有效全局路径复用候选也未达到时间门禁。失败和正常回放均保留原始证据。
