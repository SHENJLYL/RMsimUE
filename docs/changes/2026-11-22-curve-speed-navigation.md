# RMUC 路线用时排序与速度上限定位

同组测试从 (7.86, −6.78) 到 (−8.32, 6.16)。Windows 原生启动时实测小陀螺以 2 rad/s 设定转动，真值仅用于事后独立核验。

路线试验对全局代价地图中已验证净空的备选曲线做沿弧长速度估计。估计考虑曲率、切向停止距离、车辆加减速，并以累计预计时间排序。控制器的实体运动、实时局部代价地图和停止检查沿用原链路。

原生跨场墙钟 48.57 秒、物理时间 49.20 秒。检查 5,733 个位置，静态重叠 0 处。波浪路、六边形平台和出口专项共检查 1,446 个位置，静态重叠 0 处。相较原路线模型，记录的有限预计时间改善中位数 0.83 秒。真实用时仍增加，排序试验已还原。

用已采集局部栅格和标准静态图做近似切向停止分析。在 40.05 秒的旧回放中，右弯实体速度中位数 0.94 m/s，采样栅格对应的估计切向上限 3.03 m/s。左弯为 1.05 和 2.60 m/s。近似切向分析只用于诊断，运行安全依赖真实的整车扫掠。

速度日志记录控制器的曲率上限、底盘轴向与终点上限、前方制动预判及实际发送速度。独立核验同步检查实体和车端整形速度。两处弯道有 61 个低速样本先被曲率限制，26 个先被前方制动预判限制，41 个在当前指令停止扫掠阶段降到 2 m/s 以下。此统计不计提前返回的硬制动样本。弯外已发送速度、车端已接收速度及整形后的中位数分别为 2.728、2.541、1.612 m/s。原生日志对照全程静态重叠为零，终点误差 0.260 米，超出 0.25 米门限。

将横向加速度从 5 改为车包的 8 m/s² 后，左弯可用曲率速度上升，低速限制转移到了制动预判。左弯由约 10.73 秒增加到 14.21 秒。连续路径投影减少部分曲率限制，紧接的停止检查仍频繁压低速度。两种试验的各自三段平台均到达且静态重叠为零。

按实际路径切向判别弯道，避免把中等横向纠偏计作路径转弯。当前完整车身及指令停止扫掠继续执行。原生日志记录了 38 次限频纠偏区分，三段平台共 1,430 个位置均无静态重叠。试验未缩短跨场时间，额外控制代码和速度日志已还原。全部候选配置保持独立，26 秒尚未通过。
