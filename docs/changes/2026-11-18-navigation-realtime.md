# 2026-11-18 原 sentry 导航精度与标准实时性能

状态：当前工作分支复验中。最新完整发布状态以 `docs/progress/current.md` 和本轮 `release-summary.json` 为准；诊断会话各自保留原始失败与通过结果。

## 目标与接口

用户要求标准 1× 仿真、由所选 sentry_ws ROS YAML 决定导航速度与平滑/避障，并继续减小到点误差。保留原 Point-LIO、Nav2 控制器/规划器/速度平滑器/代价地图、导航云台跟随及真实安装位置的 Mid-360。车辆使用原尺度、真实轮地接触和 2000 N/m、140 N·s/m 悬挂。仿真真值仅进入独立评价。

当前 AIM 手动驾驶已在独立工作切片中更新为前进 5 m/s；本轮随后将 `ros2_ws/src/pb2025_nav_bringup/config/simulation/nav2_params.yaml` 的 `FollowPath.v_linear_max` 和 `velocity_smoother.max_velocity[0]` 从 3 改为 5。源加速 `[0.8,0.8,3]`、减速 `[-3,-3,-5]`、反向/横向限制、路径与避障参数保持。独立递归比较确认只有这两个数值叶改变，7 项源契约测试通过。外部 ROS 目标直接交给车辆执行器，手动输入平滑不再重复叠加。

## 性能实现

- 导航使用真实 Chaos 5 ms 固定步长及单调墙钟期限控制；保留全部物理步，未用时间倍率伪造 1×。手动模式的原全局子步设置保持。
- 激光只读物理查询分批并行，保留原光学遮挡、材料处理、随机数顺序及输出顺序；首批 4096 射线通过串行结果对照。
- 物理 200 Hz 与场景绘制 60 Hz 解耦，保留持久 viewport 纹理；不减少地图或车辆几何。
- 导航默认关闭未使用的 ROS RGB 图像读回；可显式启用相机。原生可见场景、TF/CameraInfo、完整 Mid-360 200k 射线/仿真秒、10 Hz 点云和两路 200 Hz IMU 保持。
- Windows 混合核心平台按当前可用 CPU Set 选择性能核心，启动前使 UE 核心预算与实际集合匹配；继承限制、显式设置、同质核心、多处理器组和系统策略有明确保留路径。当前机器实际为 8 核，UE 日志确认 `Cores=8`。不修改全局电源策略、进程优先级或其他进程。
- Point-LIO 增大原生 IMU 接收历史并及时排空回调，保留原估计公式及所选源参数。完整接收与无丢样需要各运行会话独立证据。

## 精度分析与地图

所选源 YAML 直接控制 AMCL、扫描转换和到点容差；Simulation 当前容差为 0.05 m。旧诊断 profile 保持历史值。增加只读同时间戳扫描、AMCL、TF、里程计、路径末端和终点误差分解，原 14 项动作检查及 0.25 m 到点门限保持，另列 0.10 m 精度目标。

原导航占据图含可通行性填充区，曾使 33 帧有效扫描的似然距离全部为零。新的独立定位图从固定 CAD 碰撞几何的接近竖直面生成；原规划/代价地图保持。两个 map server 的文件身份、地图坐标、实际 OccupancyGrid 内容和运行中变更均检查，显式地图覆盖优先于地图包默认声明。生成数据留在本地，来源与重建配方随代码记录。

在 rmuc-15，原始 PointCloud2 到原 LaserScan 的 4 个精确时刻回放覆盖 656 束，有限束存在性全部一致，最大距离误差 9.54e-7 m。剩余横向误差与当前二维定位观测弱约束、多峰有关。85°候选会漏掉红路约84.92°的长侧壁；复用先前75°候选可补这些面，但长壁水平法线几乎沿x，不能明显约束y，实际同录评分未显示足够依据替换。完整束数增加也未消除该多峰；本轮没有据此继续调阈值、改坐标偏移或向定位输入真值。

## 当前有界实测

所有数据来自 Windows UE 5.8.4 + 原生 RoboStack Humble。不同会话的模块、配置、地图和源哈希分别保留。

| 会话 | 实际到点误差：单点 / 航点 | 实时性 | 结论 |
|---|---|---|---|
| rmuc-10 | 0.160071 / 0.192976 m | 90 s 平均 1.000033×；滚动窗曾超过 1.02× | 14 项动作通过；实时门禁失败 |
| rmuc-14 | 0.116169 / 0.102656 m | 90 s 滚动窗 0.929854–1.134277× | 14 项动作通过；实时门禁失败；共享机器同期存在其他授权工作 |
| rmuc-15 | 0.129761 / 0.066807 m | 平均 1.000130×；81 个滚动十秒窗 0.997702–1.002222×；Draw 59.8156 Hz | 14 项动作和 32 项时钟/渲染/传感器检查通过；额外精度 3/4 |

rmuc-15 采用 source 3 m/s、候选85°图、最新手动5m/s车辆包及当前模块；原始点云诊断开关开启，8个原始buffer共126,368字节、精确匹配8/8、无预算丢弃。它是定位与性能诊断证据，后续 source 5 m/s、包默认地图、诊断关闭、可见GUI及完整兼容性需要各自复验。该次取消后停车距离 0.090203 m，观察期漂移 0。
