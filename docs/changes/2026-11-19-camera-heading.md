# 2026-11-19 C 环视、Shift 瞄准与云台方向修正

## 结果

C 长按捕获进入时的实际云台世界方向，鼠标独立环绕观察。车辆平移、底盘转向与鼠标环视均不会把旧射线命中点变成跟踪目标。Shift 瞄准使用持续更新的角方向；退出瞄准、释放 C 后保持当前角方向，新的鼠标输入立即恢复瞄准。小地图与 M 大地图箭头使用实际云台水平前向，与手动 W 前进基准相同。

AIM 最高前进目标 5 m/s、2000/140 悬挂、真实轮地接触、弗兰德斯原 World、钢轨碰撞配方及真实战雷出生点文件身份保持。

## 已定位根因

旧 `bHoldAimAfterFreeLook` 保留有限距离的 `AimWorldTarget` 世界位置。C 环视时仍每帧用“旧目标减当前枪口位置”更新云台；车体平移会改变该向量，驾驶再沿当前云台方向形成指令，导致两者一起偏转。Shift 进入也设置相同保持标志，直到出现鼠标量才解除。

旧目标有效性回退还可能在刚出生或 R 后把 C 环视射线用作云台目标。进入 C 前尚未完成的云台转动也会继续执行。C 中切换 Shift 后恢复旧 chase 角度，会将第三人称镜头角度当作 scope 的枪口角度。

地图帧原来取 `Rig->GetActorForwardVector()`，表示底盘。手动速度请求原来在本帧云台更新之前计算，在快速瞄准或自转时与实际云台／地图读数相差一帧。

## 实现

`HeldManualAimDirection` 保存单位世界方向，`bHoldManualAimDirection` 表示角方向保持。C 进入立即取实际 `aim_camera` 前向，停止追赶按 C 前尚未完成的旧目标。保持状态直接把单位方向转到车体局部系求解云台；当前射线命中点只作显示和诊断。

| 操作 | 当前行为 |
|---|---|
| C 按住 | 鼠标只改变环视角度；实际云台保持进入时的世界方向 |
| C 释放 | 按当前模式回到 chase 或 scope；保留实际角方向；丢弃释放帧的环视鼠标量 |
| Shift 进入 | 从实际云台方向初始化 scope；随后每帧计算角方向，即使鼠标量为零 |
| Shift 中移动鼠标 | 角方向持续改变，现有灵敏度和 FOV 缩放各应用一次 |
| Shift 退出 | 根据当前实际方向做一次 chase 视角投影，保持角方向直到新鼠标输入 |
| C 内切 Shift | 只改变退出 C 后使用的镜头模式；环视角度不进入云台目标 |
| R | 清除旧保持／测试目标，恢复 chase；若 C 仍按住，重新捕获复位后的实际方向 |
| 失焦与回到窗口 | 保留制动和首帧鼠标丢弃；旧 Shift 边沿不会切换镜头 |

`GetGimbalPlanarForwardRos()` 从实际云台前向得到 `(X,-Y)` 并水平归一化；缺相机／退化方向时回退到底盘前向。手动全向驾驶在本帧云台更新之后使用它，地图帧也调用同一函数。地图坐标校准、裁剪和箭头绘制保持。

原训练／接触开火夹具的弹道抬高目标改由 `bProbeAimWorldTargetOverride && bControlProbeActive` 显式控制，普通运行不会进入这个分支。ROS 底盘、云台和开火控制权边界保持。
