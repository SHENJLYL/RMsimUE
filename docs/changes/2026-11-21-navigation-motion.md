# 导航行驶速度和连续性

标准 Windows 仿真在相同 RMUC 出生点回放三个固定目标。里程计沿指令方向的实测速度进入平移 PID 的微分项，避免前视点切换带来的指令尖峰。缩短前视后，在已知可行与不可行两端之间继续查找到地图分辨率，保留已通过完整扫掠的跟踪点。

仿真配置的滚动窗口从 5×5 m 扩大到 10×10 m，沿用原 5 m 标记范围，并显式限制所检查的位移加车身和传感器余量。规划时在硬停车范围前留两个控制周期的余量。控制器连续调整曲率速度比例，提前为转弯和真实终点减速，终点限速按车辆制动能力计算。普通平移和显式零速的执行链继续分别使用原速度平滑器和直接刹停路径。

平移模式下使用测得的偏航速率和反应制动时段估计车角运动余量，同时保留包围所有朝向的外接轮廓判定。对可发出旋转指令的配置使用全旋转包络。行驶时按速度额外预留一个控制周期的侧向空间，低速靠近时余量随速度减小。

显式外部速度控制进入刹车时，底盘清理速度整形器中残留的正加速度，按车身实测前向速度约束进入刹车的电机参考量。车身运动仍由轮地接触和力矩求解决定。减速区以限速曲线约束目标速度，避免距离被 PID 和接近目标的比例项连续相乘。
