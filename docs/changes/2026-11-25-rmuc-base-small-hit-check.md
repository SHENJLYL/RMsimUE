# RMUC 基地小装甲受击复验

基地小装甲在护盾解除后接受符合条件的弹丸。裁判在表面识别之后仍要求有效法向冲击。本轮只保留隔离场次的装甲受击复验。规则依据 RMUC 2027 V1.0.0 §5.1.1 和表 5-1。 [官方发布页](https://bbs.robomaster.com/wiki/20204847/1969149?source=7)

在 UE 场景里用同一弹丸积分和裁判入口验证四种情况。护盾开启时有效碰撞扣 0 HP。护盾解除且大装甲闭合时，近水平的测试弹丸先碰到小装甲边缘下方的结构，扣 0 HP。低冲击直击小装甲扣 0 HP。有效命中小装甲扣 20 HP。原 16 个车辆装甲采样和 76 项基地装甲查询一并通过。 [原生回执](../../artifacts/unreal/base-small-hit-final-20261125T082325Z/verification.json) · [命中日志](../../artifacts/unreal/base-small-hit-final-20261125T082325Z/projectile.log)
