# RMUC 地形点云同步、缓存有效期与 RViz 显示

现有地形节点独立收配准扫描和里程计。全速基线录包中，具备可比较里程计的 822 个扫描到达时刻，有 787 个只能看到至少早 90 ms 的里程计。对 5 rad/s 的车体，100 ms 对应约 29°。车体姿态影响地形分析的裁剪、局部栅格和动态点过滤。

两个地形节点改为处理相同时间戳的 Point-LIO 扫描与里程计，并直接复制输入扫描的 ROS 时间戳。缓存点在体素重采样和地面估计前遵守现有点龄设置，远场只拼入足够新的局部地形。保留原坡度限制和实时障碍检查。RViz 当前帧显示可减少不同定位变换下的历史点云重影。

Windows 原生跨场起终点为 (7.86, −6.78) 和 (−8.32, 6.16)。导航从 RViz 实际首帧就绪后出发，全程小陀螺设定 5 rad/s。首轮启动遇到 AMCL 0xc0000005，中止并保留录包。复跑 862 帧地形点云均与输入扫描同时间戳，874 帧原始雷达全部配对。动作成功，实际终点偏差 0.237 m，原场地 7,534 个静态净空样本通过。RViz 首帧至完成 61.66 秒，物理时钟 61.34 秒。26 秒用时目标仍未通过。

波浪路、平台和出口专项静态检查状态 `passed`，各段核验样本数 579, 1411, 404。录包中两个回头弯的地图定位误差 P95 分别从 0.182 和 0.123 m 变为 0.146 和 0.107 m，其他路段从 0.240 增到 0.379 m。可见漂移包含地图定位和历史点云叠加。单次前后路径差异会影响统计，整场定位及转弯速度仍待验收。

跨场限速日志与录包代价图对齐后，两个回头弯的 606 条原速限速样本中有 527 条位于静态障碍格 0.15 m 内。其余标记还需按原始点云和地面高度核对。完整案例、时间戳、真值净空及录包结果见 [原生验证记录](../verification/2026-11-23-terrain-stamp-navigation.json)。
