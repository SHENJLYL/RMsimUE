# 全屏遮挡绘制与状态序号诊断

标准导航在 Windows 启动时向 MuJoCo 观察进程传递真实所属 UE PID。确认不透明的前台全屏窗完全覆盖观察窗口后，观察窗停止提交绘制和交换缓冲，继续记录采样。覆盖解除、置顶或部分可见时恢复显示。启动阶段依旧要求至少一个真实原生状态画面完成绘制，避免在首次绘制之前误报就绪。

状态新增接收序号缺口计数。独立原生测试共接收 6,198 个连续快照，零缺口。三组实际 OpenGL 相机验证的颜色和深度逐像素相等。显卡采集有焦点变化，按匹配片段比较只支持本轮 GPU 开销观察。完整三窗口 100 FPS 尚未通过。

反射异步及 RHI 重叠保留显式有界诊断入口。原 MSVC 求解模块、物理和显示 DLL、车辆和场地资产、全屏画质配置继续采用同一工程版本。下一步及开源依据见[性能调研](../research/mujoco-ue5-performance-20261120.md)。
