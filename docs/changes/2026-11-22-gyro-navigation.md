# 2026-11-22 RMUC 小陀螺与跨场导航

跨场验收默认启用小陀螺。从物理起点 (7.86, −6.78) 发送同一个 NavigateToPose 目标 (−8.32, 6.16)。目标耗时严格低于 26 秒，真实终点误差小于 0.25 米，同时通过完整静态净空核验。计时包含两处回头弯的减速、停车和重规划。

## 小陀螺控制

导航动作取消时由动作状态直接提交底盘制动，避免原有速度等待通信超时。约 2.1 m/s 的原生直线试验中，2 rad/s 自转档从 2.06 米缩短至 0.93 米，5 rad/s 档从 1.90 米缩短至 1.02 米。旧控制器输出和速度平滑器尾流在新动作开始前无法解除制动。

- AIM 手动、训练和 ROS 速度导航使用同一车辆配置，范围 0.1 至 5 rad/s。G 开关，Z / X 按 0.5 rad/s 调节。导航收到有效移动指令时保持目标平移方向，停车时根据最新局部代价地图验证旋转净空。空闲授权只接受零平移输入。Space、取消、过期指令和避障制动优先。
- Windows 原生导航键盘验证中，X 将设定提升到 5 rad/s，静止峰值约 4.86 rad/s。Z 可逐级降至 0.1 rad/s。最低档测试的底盘实测为 0.078 rad/s，零平移指令有效。另一次原生键盘测试验证 G 关闭后底盘停转。取消导航时，车辆即使处于小陀螺模式也会制动。
- 5 rad/s 短程导航到达，556 个静态净空检查位置通过。波浪路、六边形小平台与出口在启用小陀螺时分别通过 426、752、202 个静态净空位置。区域专项使用候选导航配置。

## 跨场复测

启用小陀螺的 Windows 原生短程对照定位到旋转轴速度平滑造成的掉速。采用固定坐标系平滑后，车体系 ROS 输出的同一段短程用时 3.19 秒，终点偏差 0.174 米，635 个净空位置无重叠。已接入默认导航，实际从默认配置启动的复测耗时 3.83 秒，884 个净空位置无重叠。默认入口三项目标通过，合计 1,556 个车身位置。默认入口完整跨场实测 61.77 秒，状态 passed，净空重叠 0。

2 rad/s 跨场候选墙钟 46.72 秒，物理时间 47.09 秒，真实终点误差 0.199 米，4,712 个静态净空位置无重叠。两处回头弯分别耗费 10.45 秒和 9.84 秒，平均车速 0.83 和 0.85 m/s。最新波浪路、小平台和出口合计检查 1,393 个位置，均无静态占用重叠。

云台跟随按速度指令的坐标系处理。固定里程计坐标系的方向直接使用，车体系速度用指令时间戳对应的估计车体朝向转换。短暂零平移时保留最近的导航方向。AIM 仿真包将世界系转向速度设为 3 rad/s，关节速度仍按现有机械限制约束。

默认导航配置下，0.1 和 2 rad/s 均通过同一段短程避障测试。标准手动和训练入口分别通过 20 个实际键盘事件，涵盖 G 开关、Z 下限、X 上限。静止 5 rad/s 档测得 4.84 和 4.87 rad/s。

5 rad/s 完整跨场回放使用预留制动空间的候选配置，通行 66.69 秒，物理时钟 67.03 秒。8,160 个静态净空位置无重叠，终点偏差 0.231 米。行进中启用云台跟随的样本 1,583 个，实际云台朝向误差中位数 0.109 rad，90 分位数 0.405 rad。计时仍未达标。
