# RMUC 右回头弯障碍来源与近场规划复测

同组物理起终点 (7.86, −6.78) 至 (−8.32, 6.16)，使用 Windows 原生 UE、MuJoCo 和 ROS 2 NavigateToPose。小陀螺在启动时已测得转动，设定为 2 rad/s。计时门槛严格低于 26 秒。

44.21 秒对照的右弯有九次实车制动，其中五次落在出弯后直段。通过同步记录的局部成本地图、地形点云和实车轨迹，对五组右侧测得的停车阻挡按时间对齐。部分动态占用离静态墙面约 0.5–0.7 米，邻近采样中未能确认这些点属于已知可通行地面。停止距离和现有障碍标记均照常评估。

| 原生回放 | 跨场墙钟 / 物理时间 | 静态重叠 |
| --- | --- | ---: |
| 原提前收速对照 | 44.21 / 43.90 秒 | 0 |
| 增加右弯原始地形采集 | 46.69 / 46.67 秒 | 0 |

横向阻尼依据横向速度抑制来回纠偏，右弯出口实际偏离路径的 90 分位从 0.209 米降到 0.159 米。右弯制动数未减少。后续中央通道超时，阻尼代码已撤回。

2 米近场结果中，出口用时从 6.42 秒减到 4.05 秒，制动次数从五次减到三次。左弯与其他路段用时增加，完整动作仍慢于最佳对照。两轮近场共享的距离仅约束新增的全局规划点云来源。局部控制器继续处理原来的近场避障点云。

1.25 米近场共享将右弯整段物理用时从 12.27 秒降至 9.37 秒，制动次数从九次降至五次。右弯出口从 6.42 秒降到 4.33 秒，制动从五次降到两次。左弯物理用时从 9.88 秒升到 14.89 秒，制动从五次升到十次。该候选跨场净空与终点均通过，完整用时仍高于 44.21 秒对照。

原生 MID360 自身回波统计覆盖 1,954 个报告，最高量得 0.237 米，没有越过当前 Point-LIO 的 0.5 米范围门槛。量测语义与原有遮挡行为保持，诊断结束后恢复正式雷达代码与引擎节拍。
