# RMUC 导航云台跟随连续性

导航使用时间戳对应的估计车体朝向，将车体系指令转换为里程计坐标系。同一导航方向在底盘旋转期间持续转换为关节目标，底盘和云台各自响应。旧实现将速度指令与点云里程计使用同一个 0.25 秒期限。5 rad/s 档短程回放中，里程计超过期限后，云台出现关节保持，随底盘转动。修复后沿用估计角速度做最多 0.50 秒的有界投影，有效导航速度结束或暂缺时保持上次有效平移方向及俯仰。估计里程计超过 0.50 秒会退出跟随。UE 角速度反馈以最短角差穿越 ±π，修正读数跳变。

Windows 默认导航入口复测实际键盘输入。X 加到 5 rad/s，Z 逐级降到 0.1 rad/s，再按 Z 保持 0.1，G 关闭后车辆制动。0.1 rad/s 档静止时，跨过验收门限的实测读数为 0.074 rad/s。该档短程到达误差 0.090 米，198 个净空位置无重叠。

5 rad/s 默认短程对照在车辆平移时采到 15 次保持源样本，修复后采到 0 次。关节角速度读数峰值由 621.04 变为 8.78 rad/s。修复版终点误差 0.173 米，876 个静态净空位置无重叠。5 rad/s 档急转时仍有指向误差，实际行进方向误差 90 分位数为 0.979 rad，同步比较发现其中一部分来自限速后的云台目标角。短程回放仅核验角度与净空。18 个控制单元测试通过。

2 rad/s 跨场使用同一组坐标与候选路线设置。桥接修复回放中，79 个移动样本的里程计延迟位于 0.25–0.50 秒且仍处于导航跟随。实际朝向误差 90 分位数为 0.271 rad。独立净空核验检查 4,585 个位置，静态重叠为零，终点误差 0.253 米，超出 0.25 米门限。

平台专项的默认路线在前往六边形平台时出现 34 个占用重叠位置，涉及 (7.125, 3.525) 和 (7.125, 3.575) 附近的两个栅格。同期真值仅用于独立核验，实际车身比估计位置约向东 0.09–0.14 米。带规划余量的弯道窗口候选通过全部三个测试，合计 1,377 个位置无占用重叠。上一版桥接的默认路线对照只通过波浪段，前往六边形平台时超时。

单独切换净空规划器的配置仍使用默认控制器和安全检查，覆盖 3 个专项点，评估状态 passed。合计 1,543 个位置，各段占用重叠计数 [0, 0, 0]。同配置跨场墙钟 55.44 秒、物理时间 55.44 秒，净空验收状态 passed。该配置保持独立。

连续跟随桥接已在默认入口启用。 ±π 角速度反馈修复已保留。

回头弯日志显示，停车约束多数来自占用栅格导致的指令减速，部分才是测得速度对应的紧急停车。尝试沿阻挡格切向调整前进方向，保持原紧急停车检查，并要求新方向仍在规划走廊内。回放中共采用 4 次切向，跨场墙钟 45.86 秒、物理时间 46.19 秒，4,511 个位置无静态重叠，终点偏差 0.206 米。该试验未缩短现有最佳跨场时间，代码已回退。

Nav2 横向速度阈值从 0.5 降至 0.001 m/s 的独立配置也完成同程，墙钟 47.24 秒、物理时间 48.90 秒，4,760 个检查位置无静态重叠。右、左回头弯分别出现 8、7 次制动，试验配置未部署。
