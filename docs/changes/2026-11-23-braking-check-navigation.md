# RMUC 整车停车检查复测

Windows 原生 NavigateToPose 使用原组坐标 (7.86, −6.78) 至 (−8.32, 6.16)，起步时实际启用 2 rad/s 小陀螺。实体运动、实时地图、整车足迹和车包限值均来自现有运行环境。

旧指令检查按目标速度立即可达来估算停车距离。可达速度版本改用 UE 实际 250 毫秒指令租约和车包加速度，检查从实测速出发在租约内能行进的距离，以及之后停车时的整车扫掠。记录到 25 条可达判定通过日志。另独立测试撤掉原多点弯道预判。
