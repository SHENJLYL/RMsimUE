# RMUC 导航用时和坡面识别

以仓库内固定的 sentry_ws 源码和同源载车配置复核。沿用 Omni PID、Theta*、代价地图的强度标记、速度平滑器和底盘扫掠。原地形节点以邻域低分位的固定高度作为地面参考，斜坡高端的高度差会越过 0.10 m 障碍阈值。

近、远地形节点现在用相邻栅格最低实测点拟合局部支持面。RMUC 仿真配置允许不超过 35° 且残差不超过 3.5 cm 的支持坡面。缺少二维支撑、陡面、台阶边缘和超出平面的点仍由原流程处理。可通行性上限由选中的 sentry_ws YAML 提供。算法只读取传感器点云，实际姿态仅供独立评估。合成坡面回归通过，原生两路地形节点均有坡面修正记录。 [原地形分类实现](https://github.com/jizhang-cmu/ground_based_autonomy_basic/blob/noetic/src/terrain_analysis/src/terrainAnalysis.cpp)

速度调整采用平移 Kp 4.0、最小前视 0.65 m、跟踪预测减速度 3.0 m/s²。浅弯使用连续的进入速度并保留实际停车扫掠，高速扫掠预留额外侧向空间。保留原路径代价权重和车辆动力学参数。仿真源及回归覆盖保持真实配置适配。
