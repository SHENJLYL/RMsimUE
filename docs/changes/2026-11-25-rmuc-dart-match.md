# RMUC 飞镖比赛闭环

比赛中 `Shift+F4` 换靶，`F4` 请求本方闸门。单按 Shift 松开时仍切换瞄具。中文 HUD 显示闸门、选定目标、余弹、可开闸次数和双方基地及前哨增益点的压制剩余时间。红蓝各自持有计数，每局最多四枚，首次和第二次开闸机会分别在开赛 30 秒和 240 秒发放。

闸门约 7 秒开启，全开后可发射 30 秒，检测窗口 40 秒，第一次关闸后冷却 15 秒。自动发射间隔 2.6 秒，场景内采用 2.2 秒的预设飞行动画。飞镖显示十字尾翼、队色镖头和尾迹，抵达虚拟检测体积后由现有裁判入口检查目标、窗口、已消耗弹量和移动稳定时间。仿真点位从当前场景模型定锚，采用简化的虚拟检测器移动。该动画不包含实机初速标定或发射解算。

表 5-2 原始结构伤害依次为前哨 1000、基地固定 200、基地随机固定 300、基地随机移动 800、基地末端移动 1250。正式扣血保留原有基地 100% 防御、阵地控制及比赛结束逻辑。基地移动类目标有效命中后展开护甲，固定类四枚有效命中后展开。连续击中同一处增益点将 30 秒失效期从最新命中重新计算。压制期间从场点观测层屏蔽对应基地或前哨读卡，恢复后使用物理车当前位置重新判定。 [RMUC 2027 V1.0.0 §5.6.1、§5.7.3 及表 5-2](https://bbs.robomaster.com/wiki/20204847/1969149?source=7)

## Windows UE5 原生复验

- 前台比赛的 `F4` 开闸和 `Shift+F4` 换靶由真实按键验证。蓝方首镖将红方前哨从 1000 打到 0 HP。第二窗最终锁定末端移动靶，三次各扣 1250 HP，基地降至 6250 HP，护甲展开。
- 隔离复验第二次开闸选择随机移动靶，蓝方用余下三枚击中红方基地，10000→7600 HP，护甲展开。蓝方最终余镖为 0，攻击伤害为 3400。
- 红车实体停在基地增益点，压制前启用，受击期间关闭，最后一次命中后自然恢复。隔离探针快进开闸前的空闲时段，开闸、飞行、压制计时按比赛时钟推进。
- UE 构建成功，四套 C++ 裁判用例与 128 项原生场地装置查询通过，窗口无 Ensure、fatal 或 assertion，测试进程清理完成。
