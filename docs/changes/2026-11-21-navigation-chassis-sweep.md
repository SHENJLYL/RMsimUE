# 导航底盘防切角与制动距离

原 Omni PID 控制器在规划路径上抽查 10 个中心点，再给出直指前视点的平移速度。按现场 2 m 前视距离复现的直角路径中，原采样点离障碍最近 0.526 m，发出的速度方向从障碍中心约 0.001 m 处经过。原地图越界分支还会提前返回可通行。

控制器现在用估计的底盘平面姿态摆放已加余量的完整足迹，沿指令线段检查连续扫掠区域和地图栅格的相交情况。局部地图的导航轴与实际底盘方向分别从 TF 取得。底盘转动期间采用包住各个偏航角的保守轮廓。切角受阻时逐步缩短前视距离，若连近点也不可达则请求重新规划。未知栅格、越界和缺失 TF 阻止本次运动。高速度时根据车包减速度、jerk、控制周期和代价地图周期估算所需制动空间，并纳入实测速度带来的侧向余量。当前配置反应余量 0.45 s、纵向减速度 4 m/s²。预测停车范围已受阻时发出有效零速，供原有即时制动链路执行。云台沿用独立的行进方向跟随。

## 原生验证

Windows MSVC 回归 13 项通过，覆盖开放通道、拐角、缩短前视、车体角部、倒车、侧向惯性、未知栅格、越界、制动余量和无效几何。标准入口的运行进程已核实加载更新的 DLL，安装副本与部署副本的 SHA-256 相同。

此前归档的三个导航目标重新运行，最终真实位置误差分别为 0.162、0.173、0.071 m。1,015 个独立真实位姿及相邻样本间的插值合计核对 1,703 个位置，带余量车身在原始静态导航占用栅格上的重叠数为零。与场地外围墙的最小平面余量为 0.670 m。此项验证覆盖静态平面地图和外围墙，动态物体以及逐物理步的碰撞冲量另需实测。

最终独立短程目标误差 0.123 m，取消后停车位移 0.144 m。18 项动作检查及 32 项时钟检查均通过，60 秒仿真倍率约 1.0000×。第一轮中间版本触发过控制器异常清图，且单独的 60 秒窗口有绘制频率分项失败，原始证据已保留。 [机器结果](../verification/2026-11-21-navigation-chassis-sweep.json)
