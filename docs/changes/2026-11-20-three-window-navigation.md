# UE5、MuJoCo 与 RViz 三窗口导航

日期：2026-11-20，Asia/Shanghai。范围：Windows 标准入口与原生状态可视化。

## 使用入口

双击 `D:\simulator\Play-Navigation.cmd`，无需附加参数，即可打开三个实际图形窗口：

| 窗口 | 内容与用途 |
|---|---|
| UE5 / RMSim | 当前 RMUC2027 场景、车辆外观、光照、交互与传感器场景 |
| MuJoCo - RMSim Live | 当前物理模型、完整场地碰撞几何，以及底盘、轮组和云台的实时姿态 |
| RViz | 地图、点云、定位、代价地图、路径和原 Nav2 目标／航点操作 |

启动器先准备 MuJoCo 显示环境和完整模型，再启动 UE 与原生 ROS 链；观察窗口完成首个有效状态的渲染，定位和 Nav2 就绪后打开 RViz。原标准入口直接获得此功能。

MuJoCo 相机支持左键环绕、右键平移、中键／滚轮缩放，Shift 切换旋转或平移方式。F 切换跟随底盘，Home 查看全场。目标和航点在 RViz 中设置。相机操作只影响观察视角。

关闭 MuJoCo 窗口或 RViz，或运行 `D:\simulator\Stop-Navigation.cmd`，由启动器结束本次会话拥有的进程。两个 CMD 入口保留实际退出码。详细步骤见[导航控制台指南](../guides/navigation-console.md)。

## 同一物理状态的两个画面

车辆由 UE 进程内的原生 MuJoCo 继续推进。新的可选发布器在原有 Step 最终状态验证之后，向本机 loopback UDP 发送完整的 qpos、qvel、act、ctrl 和所有刚体的世界位置、四元数；采样使用 30 Hz 仿真时间槽。数据携带模型／物理身份、会话 token、generation 和递增 sequence。

独立窗口使用官方 MuJoCo 4.0.1 的 mjv／mjr 渲染接口展示同一模型，按收到的完整状态更新运动学和画面，并逐个核对 16 个刚体位姿。观察窗口没有动力学推进和驾驶指令发送路径。原传感器、Point-LIO、AMCL 和 Nav2 的数据链继续工作，显示真值供可视化和独立核验使用。

显示模型完整保留 249 个源车辆凸壳、14 组固定场地三角面和边界；14 组场地包含 891,028 个顶点、1,608,500 个三角面。固定场地的显示缓存经三个关节姿态与完整场景更新对照验证。观察窗口的头灯提高了碰撞几何的可读性，调整位于本地视觉参数中。

完整模型、drive-profile、源几何和物理配置的字节身份保持。手动／导航继续采用前进 5、倒车 2.5、横移 4 m/s，加速／减速／制动 2／4／7 m/s²，以及同源 jerk 和角速度设置；原生动力学步长仍为 1 ms，UE 世界步长 5 ms。

## 修复与证据保留

实际运行发现并修复了 Windows venv 的父启动进程／实际窗口进程 PID 差异。启动器按创建时间、父子关系、实际命令参数和持有的进程句柄绑定窗口进程，继续严格核对来源与会话身份。
