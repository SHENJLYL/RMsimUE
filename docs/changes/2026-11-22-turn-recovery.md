# RMUC 回头弯速度与净空复测

从同一物理起点 (7.86, −6.78) 发送原生 NavigateToPose，目标为 (−8.32, 6.16)，起步时现场确认小陀螺为 2 rad/s。记录完整动作墙钟、物理仿真时间、真实终点偏差和静态车身净空。

较快基线中，右弯与左弯最终下发速度中位数为 1.91 和 1.87 m/s，车端整形后为 1.12 和 1.28 m/s，实际速度中位数约 0.73 m/s。选择更多前视点的一轮反而增加了频繁制动，后续候选改为处理确切的边界停滞。

| 低速驶离并保留单次限速试验 | 终止于 11.98 / 14.82 s | 38 | 0 |
| 单独验证低速驶离 | 40.61 / 43.97 s | 0 | 0 |

右回头弯停滞时约位于 (7.43, 4.21)。传感器仍持续提供新数据。距离估计车心最近的占用格中心约在 0.449 米处。以该次占用网格和局部路径计算，裕量内七个占用格均在运动方向后方，最近格边约 0.418 米，硬轮廓半径约 0.387 米。低速恢复仅在原硬扫掠通过、原裕量中已有的后方已知障碍不会离车身更近时放行，速度上限 0.55 m/s。前方障碍、朝障碍方向的残余滑移和未知格均通过阻挡回归。

组合候选出现 38 个静态重叠检查位置，动作终止。该轮未触发低速驶离分支。随后回退车端单次裁剪试验，隔离验证低速驶离。

隔离复测完成跨场和三个平台目标。跨场净空检查 4,378 个位置，真实终点偏差 0.229 米。未记录低速驶离触发，墙钟与物理时间相差 3.36 秒，不能归因于驶离分支。独立记录表明约 3.3 秒差值集中在动作的前 6.4 个物理秒。

物理补跑实验以 50 毫秒为积压期限，超过后重新对齐下一次墙钟期限，MuJoCo 继续按固定步长积分。该轮墙钟 46.24 秒，物理时间 46.17 秒，静态净空重叠检查数为 0。引擎原有节拍已恢复，证据保留在试验目录。
