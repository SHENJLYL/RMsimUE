# RMUC HUD 提示音

增加原创短促 2D 提示音，由裁判状态驱动播放。画面使用的 HUD 层可独立切换。

- 命中使用裁判确认的计数。每次更新合并同一帧命中，快速连续事件至少间隔 75 ms。机壳、墙面或无效接触仍只具有原场地声音。
- 热量超过上限的 85% 时蜂鸣，持续超阈值时每 1.65 秒最多一次。冷却至 80% 重新进入可提醒状态。HUD 调试热量预览只影响显示。
- 开赛前和比赛末尾的 5 至 1 秒逐秒提示，开赛和比赛结束分别有独立音型。两套 HUD 在倒计时阶段均显示相同的剩余秒。`F7` 重开进入五秒倒计时，`F6` 可立即开赛。已有 `-RefereeCountdown` 可在启动时进入开赛倒计时。

生产运行使用裁判正常的时钟、加热、扣血和确认事件。开发用 `-RefereeHudAudioSelfTest` 检查五个原始 PCM 声音；`-RefereeHudAudioTrace` 输出播放、倒计时和热量日志。`-RefereeHudAudioThermalProof` 用标准发射接口持续射击、冷却、再次升温，仅用于自动验收。

Windows 隔离原生证据位于 `artifacts/unreal/rmuc-hud-audio-20261124T133023Z`。有效弹丸验收同帧合并成一次确认音，五段 PCM 自检通过。真实开赛时钟依次播放 5、4、3、2、1 秒和开赛音。持续射击在真实炮热比 85.3% 首次播放蜂鸣，冷却后于第二次升温播放。记录包括音频设备就绪和实际创建 2D 声音实例。比赛末尾的提示接入同一裁判时钟，原生验收覆盖开赛倒计时。
