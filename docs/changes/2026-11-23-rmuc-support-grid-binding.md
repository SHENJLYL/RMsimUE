# RMUC 默认导航支持网格路径绑定

启动器原本只匹配未加引号的 `terrain-support.bin`。本地发布配置已使用带引号的 Windows 绝对路径，配置和网格哈希均通过校验，但生成运行配置时误报没有引用。

绑定阶段现在读取 YAML 标量，统一使用当前地图包中通过校验的支持网格。裸文件名、带引号文件名和绝对路径均可用。原始导航模板及地图包声明保留原字节。

用当前本地 RMUC 包通过地图准备、三个网格引用绑定与 Nav2 参数预检。原始 YAML SHA-256 为 `09f7b6fba60ee0d28cf700f5842eb2d382a845617238026ae06269acf66f6537`，`curve_clearance` 保持 0.60。控制台与出生点共 23 项测试通过；原有目标源测试中有 3 项与当前本地 AMCL 和规划器配置预期不符。本次验证覆盖启动前配置。
