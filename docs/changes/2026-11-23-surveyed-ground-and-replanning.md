# RMUC 坡面点云和整条重规划净空

地形节点在发布前按同一扫描时刻的 TF 将回波与场地测绘高度比对。在至少 25 个不同平坦参考格形成一致的高程偏差后，才将距连续可通行表面 3.5 厘米内的障碍高度回波降为实际表面残差。保留原点坐标和扫描时间。墙边掩码、台阶、超坡度和缺测区域保留原分类。两个节点均由当前地图包提供高度数据，其他地图可以继续使用点云地面拟合。

平滑规划器检查从当前位姿到路径起点的连接和所有后续线段。0.05 米网格每至多 0.025 米采样。期望净空 0.84 米，曲线的最低发布净空 0.49 米。失败时重新计算整条平滑曲线，仍不合格时返回规划失败。局部区段拼接实现已移除。

回放使用一份完整跨场录包和一份波浪路、平台、出口录包。每个点在修复前后保持相同的输入、时刻和坐标。表内目标用测绘高度与录包变换筛选。回波计数跨帧重复，坡面组和波浪组有交集，其余回波未全部人工标注。
