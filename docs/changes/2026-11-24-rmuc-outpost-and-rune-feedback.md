# RMUC 能量机关颜色与前哨控制反馈

中央转盘是中央装配区上方的能量机关。转子仍使用源 CAD 的 381,346 个三角面，拆出 25 个涂装材质槽，区分两侧靶面。待机保留原有底色，发光继续由有效靶面与激活状态控制。小地图上方显示 `F5` 激活次数或当前完成组数。前哨装甲标记随塔体所属阵营着色，塔体被摧毁后熄灯。[官方场地图纸](https://bbs.robomaster.com/article/1970956)

前哨阵地包括前哨站增益点和相邻的中央高地增益点。HUD 用实测激活状态显示争用、5 秒夺取、临时控制、回退或完全控制，并独立显示塔体存活、血量和所属方。切换和重建发出裁判事件。根据 V1.0.0 §5.6.1–5.6.2 与规则答疑 #192，前哨被击毁后，因该次击毁而使完全控制易手时，塔体归新控制方并以 500 HP 重建。现已覆盖先临时控制再击毁，以及先击毁再转为完全控制。当前占点信号来自 CAD 地面读取和图纸推定区界。[官方规则](https://bbs.robomaster.com/wiki/20204847/1969149?source=7) · [官方答疑 #192](https://qingflow.com/appView/g79clgn1kk02/shareView/g79clh9dkk02?applyId=800986911)
