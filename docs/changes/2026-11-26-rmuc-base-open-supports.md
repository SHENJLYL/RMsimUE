# RMUC 基地展开支撑和阵营灯条

原 CAD 的外壳主件与紧固件是不同的连通体。每块外壳的十个紧固件已随原件一起分到活动网格，红蓝共六十个。展开时可见的内柱原来与 CAD 顶壳之间有约 48 mm 间隙。延伸内柱，使其上下分别接入底座与顶壳。同时增加贴合原壳背面的滑靴，以及固定导向座的安装法兰和上沿。补制连接件用于显示，沿用原滑移和外翻轨迹。
