# RMUC 同源场馆与庭院远景

最近一次导航会话的场馆 layout 哈希与当时活动的 42 m 版配置相同。红方波浪区原生追尾复拍确认，两侧远景墙仍在门窗中占据较大视野。本轮保留墙高，沿 X 轴向外再移 34 m，把连续墙放到校园草坪外缘附近。墙内面为 ROS X=-76.0158752 m 和 +75.9841248 m，距馆外侧台阶约 48.26 m。两段直墙各长 136 m，两端沿用 4.3 m 折返，共 112 个原砖墙模块。场地碰撞与 MuJoCo 绑定继续使用既有资产。

`assets/maps/rmuc2027/map.json` 作为正常模式的共同场景来源。手动、训练和 Linux 手动指向该文件。导航从它生成运行场景，只套用导航包指定的红方波浪出生点。启动前同时检查规范地图、导航包验证场景和栅格的几何身份。两种 Windows 导航后端都从同一个 `arena-shell.json` 逐字节生成会话场馆及 layout 快照，使用同一主渲染配置。Linux 手动脚本也选用该配置及 Vulkan SM6。玻璃和云影的材质沿用活动场馆定义。

## 验证

- 57 项 Windows 启动合同通过，包含 Chaos 导航的 RMUC 场馆快照及渲染配置。规范场景和导航会话数据除了出生点完全一致，会话场馆、布局和来源文件与规范场馆逐字节一致。Linux 已通过 Bash 语法检查，原生渲染待验。
- 在同一红方波浪区出生点、固定云时刻以及同样 2560×1440 TSR 50% 条件下复拍。前、后图片里门窗和机器人位置一致，新墙在门外视野占据的高度明显减小。手动源地图的东门、西门原生截图均通过各 96 项边界扫掠。 [场内追尾前后对照](../../artifacts/changes/rmuc-shared-venue-20261121/chase-wall-comparison.jpg)
- 新版全屏 Windows 导航达到定位、挂图、Nav2 和 RViz 就绪，实际状态使用原生 1 ms MuJoCo。会话退出码 0，原始来源报告记录与规范场馆相同的 layout SHA256。手动和训练共用的 Windows 入口完成默认地图、模型及运行库预检。 [验证摘要](../verification/2026-11-21-rmuc-shared-venue.json)
