# RMUC 车辆行驶与接触声音调校

旧版护墙复测在同一帧播放了墙撞和落地。墙的法向速度约 206 cm/s、冲量约 34.54 N·s，副地面接触只有 61 cm/s、1.36 N·s，音量却接近墙撞。旧马达录音在约 945 Hz 处有明显窄峰，行驶时播放速度变化范围较大。

用四段 CC0 实录替换电机、轮地循环、护墙和落地。电机改为小型电动车的连续运行录音，较旧样本的 RMS 低约 10 dB，最强单频能量占比从 8.49% 降至 2.19%。滚动用软轮在混凝土上的录音。撞墙与落地改用橡胶锤敲击金属和混凝土的短样本，90% 能量分别落在 60 ms 和 39 ms 内，原值为 330 ms 和 412 ms。[电机录音](https://freesound.org/people/JeroenWals/sounds/592497/) · [软轮录音](https://freesound.org/people/FOSSarts/sounds/740124/) · [撞墙录音](https://freesound.org/people/qubodup/sounds/54850/) · [落地录音](https://freesound.org/people/This_Is_A_Hoax/sounds/354111/)

电机变调范围收窄至 `0.94–1.06×`，滚动范围为 `0.92–1.09×`，对变速和音量平滑。低速和小角速度死区压住静置抖动，轮子离地后滚动声淡出。车辆接触按 MuJoCo 实际速度、法向和冲量选取主撞击。墙撞发生后，持续抵墙期间不会重复触发，同一撞击带来的地面声被合并。真正的独立落地仍可播放。车辆碰撞录音使用原播放音高，按冲击强度调节响度。

原始素材编号、剪辑区间、许可及哈希见 `assets/audio/rmuc2027/SOURCES.json`。四段素材为同类实物录音，未进行 AIM 实车录音标定。

## Windows 原生对照

- 同一护墙出生位置和驱动参数下，旧版一次撞墙叠放一声落地，新版全程只播放一次墙撞。原生接触速度为 206.61 cm/s，冲量为 38.411 N·s。
- 同一堡垒下坡用例仍能播放独立的落地声。两次落地相隔约 0.46 秒，之后还有一次单独的侧向接触，三者未同帧叠放。
- 原生 PCM 检查验证空闲为静音，行驶、自转和摩擦轮三组模拟均生成非零采样且无削波。两条物理路线和 WASAPI 录音播放事件均通过。
