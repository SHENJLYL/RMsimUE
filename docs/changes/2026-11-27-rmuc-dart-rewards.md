# RMUC 2027 飞镖命中奖励

统一从虚拟检测器确认命中结算。基地保护和能量机关防御可挡普通伤害，飞镖扣血按原始结构伤害结算。随机移动靶和末端移动靶对敌方存活地面机器人分别扣除当前最大血量的 20% 和 50%。复活无敌对该扣血无效。实际损失计入进攻方队伍伤害，击毁走共同战亡流程。 [官方规则与答疑入口](https://bbs.robomaster.com/wiki/20204847/1969149?source=7) · [无敌判定答疑](https://qingflow.com/appView/g79clgn1kk02/shareView/g79clh9dkk02?applyId=801394228) · [基地防御答疑](https://qingflow.com/appView/g79clgn1kk02/shareView/g79clh9dkk02?applyId=803226694)

进攻方活步兵平分固定靶 200、随机固定靶 600 或两类移动靶 2500 经验。步兵采用生命优先底盘和冷却优先云台的仿真默认配置，经验逐席保存，复活保留，按级别更新当前及最大血量、功率、冷却和热量上限。小能量机关在有效期内为新增飞镖经验提供双倍，额外经验共用 1200 上限。随机固定靶令防守方当前持有的跨越和能量机关效果暂停，倒计时继续。移动靶命中使这些已有效果失效。增益点实物读卡和阵地计时仍继续。

前哨和固定类靶按共享命中序列遮挡 10、5、3、2 秒。移动靶每次遮挡 10 秒，重叠时间累计。受影响的本机操作席切换到裁判地图，地图隐藏车辆位置。手操车辆可以左键发出地图点位指令，两次至少相隔 3 秒，Esc 或制动可取消。点位控制由原车辆物理执行，目前采用直线接近，沿途碰撞由物理求解。外部 ROS 自主席继续使用其自有控制和相机链路。

Windows UE 5.8 构建通过。五套裁判测试覆盖飞镖、场地、补给、跨越和能量机关。原生 3v3 用确认检测器测试事件核验受保护基地扣血、按席平分及升级、移动靶对有无敌的活车和低血量车扣血、护甲展开、阵营总伤害、已有增益暂停与恢复或失效。原生地图输入测试核验首条指令、过早拒绝、3 秒后再接受和取消。 [原生回执](../../artifacts/unreal/rmuc-dart-rewards-20261127T045346Z/verification.json) · [遮挡实拍](../../artifacts/unreal/rmuc-dart-rewards-20261127T045346Z/blackout.png)
