# 校园体育馆与连续玻璃围栏验收

## 目标及当前状态

按用户参考图，将 RMUC2027 放在拟真校园体育馆中央，补齐室内建筑、照明、看台和分格玻璃围墙。用户最新要求为固定关闭的装饰玻璃门，车辆始终留在场地内，无 F 键开门交互。

本功能通过 Windows 原生限定验收。主分支体育馆切片完成编译、四视角原生检查、严格 PNG 校验及独立助手画面复核；最终围墙的六项真实车辆碰撞检查全部通过。当前导航工作区的 `realtime-04` 在完整 90 秒窗口内通过动作 14/14、时钟 32/32，单点真实误差约 7.01 cm、两航点终点约 6.49 cm，退出码 0，清理无错误，输入身份保持。

源场地和车辆尺度保持，悬挂为 2000 N/m、140 N·s/m；导航速度、平滑变速和避障仍由所选 sentry_ws 配置控制。本轮实时测试采用 640×360 视口、60 Hz 场景目标、5 ms 固定物理步长、`cameraHz=0`，生产 LiDAR 及 IMU 预算保持。
