# sentry_ws 原导航高速与实时仿真

用户要求导航线速度上限暂时匹配 AIM 手动模式，由 sentry_ws 配置持有变速、避障、限速，允许未来新车辆提供独立 ROS 2 参数。完整目标还包括 1× 真实时间仿真。

## 已实现

- ROS 工作副本 `ros2_ws/src/pb2025_nav_bringup/config/simulation/nav2_params.yaml`：`v_linear_max=3.0`m/s，速度平滑器 x/y 上限 `[3,2]`、下限 `[-1.5,-2]`m/s，平滑加速度 `[.8,.8,3]`、减速度 `[-3,-3,-5]`，与 AIM 车包实际前进/后退/横移和底盘制动相符。目标接近减速提前到 2m，保留原 Theta*、PID 追踪、曲率限速、IntesityVoxelLayer 与代价地图。原下载版 `third_party/sentry_nav_original` 保持只读。
- RMSim 图形导航入口默认直接读取该 YAML；`-NavigationSource <另一辆车的ROS导航YAML>` 可切换导航参数，无需在仿真端添加该车专属速度常数。另有 `-NavigationFollowProfile` 注入高层云台跟随配置。
- Point-LIO 也从相同 YAML 读取原模型滤波参数（8 点、0.2m 体素、ivox18）；重力、IMU单位、传感器外参和时间戳仍由当前 UE 车辆状态给出。
- 7 项导航来源单测通过；最终离线 129 项中 127 通过、2 项因 Windows 符号链接权限跳过。原生桥源码/安装哈希已校验；`checkpoint-summary.json` 汇总来源、验证与缺口。

## 原生高速验收（实车真值仅独立评测）

| 试验 | 单点误差 | 完整双航点往返终点误差 |
|---|---:|---:|
| 3m/s，10ms 步长，原模拟参数 | 0.650739m | 未执行 |
| 3m/s，5ms，原模拟参数 | 0.182462m | 1.394717m |
| 5ms，提前减速/路径插值 | 0.210421m | 0.937436m |
| 5ms，平滑器匹配底盘加减速 | 0.192360m | 0.963233m |
| 5ms，诊断保持云台静止 | 0.220014m | 1.316213m |
| 5ms，加上 sentry_ws Point-LIO 滤波 | **0.200725m** | **0.388199m** |

所有原始失败证据保留在 `artifacts/navigation/nav-speed-20261117/`。原 Nav2 action 成功还需独立的真实位置检查，0.25m 门限保持不变。最后试验的完整往返仍超门限；当前状态为工程实验分支，不能标记完整高速导航已验收。

### 实时性能

5ms 动态路段只读钟表观察器在约 22s 墙钟内读得仿真倍率约 **0.437×**，观察器记录了重复状态并标记 incomplete，数值只供定位性能问题。10ms 的部分空闲时段曾约 0.8–0.93×，但定位精度未通过单点。当前没有稳定 1× 真实时间与高速完整路线同时通过的证据。

## 接续

1. 分析高速度下 AMCL/Point-LIO 与独立真值的时间序列、车体横向侧滑及漏采的 200Hz IMU；隔离接触误差与估计漂移。
2. 分离 Unreal 渲染、Chaos、激光射线计算负载，争取 1× 实时与传感器频率保持；更改物理步长须重复真实路线验收。
3. 外部新车 YAML 可指定导航来源；整车 mesh-rig/动力学/传感器的自动联动导入仍需端到端验证。
4. 双航点、取消、断线与真实 R 复位在新高速和 Mid-360 组合重复通过后才能合入 main；已验收 main 维持原状。
